# Rock Paper Scissors Game ✊📄✂️

An interactive Rock Paper Scissors game where a player competes against the computer.

## Features
- Random computer move generation
- Win / Lose / Draw logic
- Interactive UI with result messages
- Color feedback for game results

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Select Rock, Paper, or Scissors.
2. The computer randomly chooses its move.
3. The result (Win, Lose, or Draw) is displayed instantly.

## Project Purpose
This project demonstrates **JavaScript logic building, DOM manipulation, and event-driven programming**.
